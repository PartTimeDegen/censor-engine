# Tests Readme

This readme has been made to provide a bit of guidance on the tests.

# # Unit Tests

The format for unit tests should be as followed:

- Script test
    - Class Test for Model
        - Function test for initiating the model
        - Class test for generated fields
            - Function test for baseline performance
            - Function test for other cases
        - Class test for methods
            - Class test for Methods
                - Function test for baseline performance
                - Function test for other cases
        - Class test for properties
            - Class test for properties
                - Function test for baseline performance
                - Function test for other cases
